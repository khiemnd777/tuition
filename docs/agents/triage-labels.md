# Triage Labels

No external issue tracker is currently configured for this local repo.

Canonical roles to use if an issue tracker is added later:

- `needs-triage`: maintainer needs to evaluate.
- `needs-info`: waiting on reporter or operator detail.
- `ready-for-agent`: fully specified and safe for an agent to implement.
- `ready-for-human`: requires human implementation or approval.
- `wontfix`: will not be actioned.
